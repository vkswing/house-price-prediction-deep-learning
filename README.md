# House Price Prediction using Deep Learning

## Overview

This project uses deep learning to predict whether a house belongs to a higher or lower price category based on housing characteristics.

A neural network was developed using TensorFlow and Keras, with data preprocessing performed using pandas and scikit-learn. The model demonstrates an end-to-end deep learning workflow, including data preparation, model training, validation, and performance evaluation.

## Dataset

The dataset contains housing features used to train a neural network capable of predicting house price categories.

## Deep Learning Workflow

1. Load the dataset
2. Explore and preprocess the data
3. Normalize features
4. Split into training and testing datasets
5. Build a neural network
6. Train the model
7. Evaluate model performance
8. Visualize training accuracy and loss
